# アプリ名を「きょうめし」に変更

ユーザーが選んだ名称と副題を採用した。

```text
きょうめし
まわして決める。選んで探す。
```

画面見出し、副題、ブラウザーのタイトル、iOSホーム画面用の名称、利用規約・プライバシーのアプリ名と戻るリンク、SVGのアクセシビリティ用タイトル、READMEと開発案内の表題を変更した。アイコンは文字を含まないため、図柄とPNGは維持する。

公開URL・Worker名・Durable Objectの識別子・保存済み回数・Google検索・Cloudflare Accessは変更しない。過去の実装記録に記載された旧名は、当時の記録として維持する。

## 確認

- 配信資産13点を再生成。名称を含む4点で新名称と旧名称の除去を確認した。
- Wrangler dry-runと本番デプロイに成功。変更4点をアップロードし、既存9点は再利用した。
- 配信したファイルのローカル表示で見出し・副題・ブラウザータイトルを確認し、確認画像を保存した。
- 本番URLは未認証でCloudflare Accessのログイン画面へ転送された。今回の確認環境にログイン済みセッションがなかったため、本番の認証後画面の再確認はしていない。
- 表示テキストだけの変更のため、新しいテストは追加せず、Google検索も実行していない。一時プレビューは確認後に停止した。

```text
production_version: 21a25207-152f-4672-af09-02ba506ace01
```
