# iPhone ホーム画面アイコンの追加

## 目的と変更

iPhone ホーム画面で文字だけの代替アイコンになっていたため、専用アイコンを追加しました。既存画面の濃紺・コーラル・オレンジ・ミントを使い、お皿とカトラリー、サイコロで「食事をランダムに選ぶ」用途を表現しています。

SVG を正本として、180 / 192 / 512 / 48 px の不透明 PNG を生成します。HTML に相対パスの Apple touch icon、PNG / SVG favicon、およびホーム画面名を追加しました。アプリの操作、食事データ、スタイル、JavaScript は変更していません。

## 検証

- PNG 全 4 件の指定寸法と、不透明な四隅を含む RGB 出力を確認。
- SVG から生成した大サイズとホーム画面サイズの見た目を確認。
- HTML のアイコン参照先が存在し、JavaScript・CSS が変更されていないことを差分で確認。
- 公開反映と iPhone 実機での表示は、このローカル実装記録の時点では未確認。

## 運用

SVG を修正した場合は README の再生成コマンドを使い、PNG も一緒に更新します。今回の ImageMagick 環境ではグラデーションや塗りなしの線が意図どおり描画されなかったため、単色の塗りと図形の重ね合わせに統一しました。再生成後は寸法だけでなく見た目も確認します。

iPhone の既存ホーム画面アイコンはキャッシュされることがあるため、公開反映後に必要に応じて再追加します。
