# 検索条件と利用回数の表示

## 依頼と変更内容

評価に3.5以上と指定なし、口コミに指定なしと1,000件以上、距離に100mと500mを追加する。月の検索回数と残り回数を、検索する前にも確認できるようにする。

既存の初期値（評価4.0以上、口コミ100件以上、5km以内）を維持し、選択肢を追加した。指定なしではその項目が未掲載でも候補に残す。評価が未掲載の店舗に星0を表示せず、情報がない旨を表示する。距離は1km未満をmで案内する。

画面を開いた時点で利用回数を取得し、全利用者合計の今月の使用回数、月の残り回数、本日の残り回数を表示する。検索後も返された回数で更新する。読取りに失敗したときは未確認と表示し、0回と推測しない。古い読取り応答が検索後の値を上書きする競合を防ぐ。

## 回数取得APIと上限の維持

```text
GET /quota
```

既存のSQLite Durable Objectと同じ保存キーから、日・月の回数を一度に読み取る。Google通信、回数の予約、保存値の更新・リセットは行わない。米国太平洋時間の日・月切替は応答の計算にだけ適用する。未作成状態だけを0と扱い、不正な状態や保存障害では失敗する。

検索が停止中でも回数を読める。Cloudflare Accessは全経路で継続し、同一オリジンのGETでOriginが省略される場合だけ例外扱いにする。明示されたOriginは完全一致を要求し、検索POSTの検証は維持する。応答をキャッシュしない。

```text
Worker: lunch-gacha-search
DO namespace: 25269a3221d149ca8770a6b48e86ce98
class: SearchQuota
binding: GLOBAL_QUOTA
object name: lunch-gacha-global-v1
state key: quota-v1
limits: 20/day, 600/month
```

評価の指定なしではGoogleへの最低評価パラメーターを省略する。[Google公式の最低評価仕様](https://developers.google.com/maps/documentation/places/web-service/text-search#minrating)を確認した。静的資産の配信より先に回数取得経路を処理する設定を追加した。
