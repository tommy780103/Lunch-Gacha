# 検索条件の自由入力と口コミ5,000件以上

## 変更内容

評価・口コミ件数・現在地からの距離の各選択肢の末尾に「自分で入力」を追加する。選択した項目だけ数値入力欄を表示し、既存の選択肢へ戻したときは手入力欄を非表示・無効にする。口コミ件数には「5,000件以上」も追加する。初期値は評価4.0、口コミ100件、距離1kmを維持する。

入力範囲は既存APIと一致させ、評価0〜5と距離0.1〜50kmは小数を許可し、口コミ0〜1,000,000件は整数だけを許可する。空欄・非数値・範囲外・口コミ小数を現在地取得やAPI送信の前に検証し、既定値への置換や範囲端への丸めを行わない。

条件変更で前の検索結果を無効にする。処理中は数値欄も無効にし、処理後も非選択の数値欄は無効のままにする。検索結果に表示する条件は入力した小数を保持し、店舗カードの距離表示とは別に扱う。

サーバーは既に範囲内の任意数値を受け入れるため、本体の変更は不要。Googleの評価指定は従来どおり0.5刻みで切り下げて問い合わせ、取得後に入力した正確な評価・口コミ・距離で絞り込む。

全利用者合計の日20回・月600回、既存のDurable Object、本人限定認証、複数ジャンルの順次検索を維持する。
